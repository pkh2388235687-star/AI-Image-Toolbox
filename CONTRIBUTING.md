# Contributing / 贡献说明

Describe the problem and expected result before changing behavior. Keep Windows and Android formats interoperable, preserve input files, avoid overwrites, and keep processing local. UI strings must support Chinese and English.

修改时说明问题及预期行为，保持两端格式兼容、原文件不被修改、重名不覆盖、处理本地运行，并同步中英文界面。

Follow [build instructions](docs/BUILD.en.md) / [构建说明](docs/BUILD.md). Run relevant tests and report environment, results and untested cases. Do not commit generated previews, caches, personal images or signing secrets. Use small synthetic fixtures and preserve copyright notices.

提交前运行相关检查，填写环境、结果及未覆盖范围。不要提交预览图、缓存、个人图片或签名秘密；使用小型合成测试样本，保留许可及版权声明。
