# Security / 安全报告

Do not post signing keys, passwords, personal photos or workflows in public issues. Use GitHub private vulnerability reporting if enabled; otherwise describe only non-sensitive symptoms and request a private reporting channel.

报告问题时不要公开签名密钥、密码、个人照片或工作流。仓库启用 GitHub 私密漏洞报告时优先使用；否则先公开描述不含敏感信息的现象，请作者提供私密沟通方式。

File disguise and pixel scrambling are not password encryption. Treat restored files as untrusted. The app does not automatically execute them. Use synthetic reproductions for traversal, malformed metadata and resource-exhaustion reports.

文件伪装与像素混淆不等于密码加密。还原文件应按未知来源处理；程序不自动执行。路径穿越、损坏元数据或资源耗尽问题请使用合成样本复现。
