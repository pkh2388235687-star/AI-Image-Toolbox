# AI Image Toolbox

[English](README.en.md) | 简体中文

仓库名：`AI-Image-Toolbox`（AI 图片工具箱）；应用名称：`AI Image Editing Tools`。

由 **光影若水（Guangying Ruoshui）** 制作的本地图片工具集合，提供 Windows 与 Android 原生客户端，支持中英文界面。

## 下载与运行

| 平台 | 最新文件 | 要求 |
| --- | --- | --- |
| Windows | [AI-Image-Editing-Tools.exe](releases/Windows/AI-Image-Editing-Tools.exe) | Windows 10/11，.NET Framework 4.8 |
| Android | [AI-Image-Editing-Tools.apk](releases/Android/AI-Image-Editing-Tools.apk) | Android 5.0 / API 21 及以上 |

Windows 双击 EXE；Android 允许当前下载应用安装 APK 后安装。两端应用名为 **AI Image Editing Tools**。设置中可切换中文与英文，制作信息保留作者署名。

## 功能

| 功能 | 说明 |
| --- | --- |
| 双图切换 | 封面与隐藏图合成动态 PNG；单独封面、文字、位置、编号和批量导出；同页还原旧双图 |
| 背景显图 | 独立彩色/黑白透明 PNG 合成，不加文字或编号；白底/黑底效果预览、批量导出及显示图提取 |
| 图片混淆 | 本地像素重排、解混淆、批量处理；自定义 JPG 质量百分比与实际编码大小预览 |
| 文件伪装 | MP4、ZIP、RAR、7Z 的四种封装方式：copy /b 等效 JPG 拼接、原有 JPG、PNG 内嵌 ZIP、PNG IDAT 内嵌 ZIP；批量封面、文字和编号，SHA-256 校验还原；视频用 `_v2i`，压缩包用 `_a2i` 命名 |
| 合成 GIF | 队列排序、帧间隔、循环设置及本地预览 |
| 清信息 | 清理 WebUI/ComfyUI 工作流、提示词等元数据；支持 PNG/APNG、JPEG、WebP、GIF |
| 打码 | 马赛克、模糊、颜色遮盖；框选、画笔、最多 50 步撤销/重做及完整图片导出 |
| tag 读取 | 独立显示 WebUI 与 ComfyUI 正负提示词及参数，逐项复制，分别导出 TXT；空板块跳过 |
| 二维码制作 | 网站链接二维码、图片叠加、白边调节、相机/图片扫码、结果复制和浏览器跳转 |
| 设置 | 语言、默认参数、保存位置记忆与作者信息 |

Android 使用可收起的菜单；队列约占可用屏幕的 29%，同时显示三条记录，文件名单行并省略中间内容。位置菜单显示三行，可滚动选择。相册和自定义文件夹保存方式可记忆，支持系统文件分享。打码页面停止滚动满两秒后才允许涂抹。Windows 支持预览随窗口变化、滚轮缩放、中键移动和板块高度调整。

## 使用边界

- 图片混淆的“原图质量”附带原文件，使用“还原原文件”可恢复完整字节。无损 PNG 仅保证像素；压缩 JPG 有损，不能还原原文件。混淆不是密码加密。
- 双图切换还原的是隐藏图像；不等同于恢复导入文件的全部元数据或文件字节。
- 文件伪装不转码原视频，默认保留原有 JPG 方式。JPG 改成原压缩包后缀的识别依赖解压器；不能保证视频仅改成 MP4 就能播放。PNG 的两种方式统一改成 `.zip`，解压后取出完整原 MP4、ZIP、RAR 或 7Z 文件，也支持本工具一键还原。PNG 和 IDAT 均为实验方案，测试范围见[验证记录](docs/VALIDATION.md)。IDAT 方式包含图像流后附加数据，不保证所有 PNG 解码器兼容；重新编码可能删除数据。
- 发送带隐藏数据的图片需选择原图，接收后保存原图。截图、重压缩或平台处理可能破坏隐藏数据，本次新增方式尚未完成真实 QQ 群往返验证，不能承诺解决群成员看不到图片的问题。
- 默认有界预览和逐个批处理适配较低配置设备，但超大图原尺寸处理仍受手机内存限制；未在所有 2015 年手机上验证。
- 所有处理在本机进行。Android 没有联网权限、WebView 或远程加载代码。

## 双图切换

将封面和原图合成动态 PNG，保留原有封面文字、位置、编号和批量操作。还原区自动识别动态双图及旧透明双图。平台重新编码或丢弃动画帧可能只留下封面，不能保证上传后仍能切换。

## 二维码制作与扫码

页面位于设置上方。填写完整 HTTP/HTTPS 网址，例如 Pixiv 作品页；软件不上传图片，也不生成托管地址。二维码存的是网址，手机扫码后打开该网站，下载与登录权限由网站决定，不能承诺直接显示或下载原图。

网址输入支持换行显示和“粘贴网址”。“直接生成二维码”输出紧凑二维码；“图片附上二维码”可选择底图，拖动码区或输入横向/纵向百分比。导出自动放入所选根目录下的“二维码制作”子文件夹。白边可调 0–12 格，推荐至少 4 格；过小白边可能影响系统相机扫描。图片叠加时可添加最多 32 条文字，各条分别拖动、定位、修改颜色或删除。原双图及文件伪装的文字功能也支持多条。所有文字图层菜单实时显示当前文字，超过 18 个文字单元时缩略显示。拖动时合并连续位置更新，释放后提交最终位置；Windows 鼠标停在数值框的输入区或箭头区时，滚轮直接按设定步长调整数值，无需辅助键，也不会同时滚动页面；同一行控件垂直居中。

扫描支持导入清晰图片，以及相机。解析结果先显示网址/域名，点击“打开扫描的网站”才跳转；“复制扫描结果”复制完整内容。仅 HTTP/HTTPS 结果允许网页跳转。Android 相机权限只在扫码时请求，无相机或拒绝授权仍可导入；Windows 使用系统 Media Foundation 采集，按设备提供的尺寸协商 RGB 画面；优先普通彩色相机，可切换设备或重新连接。错误提示区分权限、媒体组件、格式和设备故障，并提供相机隐私设置入口。Android 优先后置相机，按支持尺寸和 NV21/YV12 格式配置，处理方向、对焦及关闭释放。没有可用相机仍可导入图片；不同硬件支持范围取决于系统和驱动。

导入透明 PNG 扫描时自动尝试白底和黑底，无需手动转成黑底图片。背景显图的“彩色叠显 → 处理方式 → 二维码优化”适用于本工具生成并保留码区参数的 PNG：该选项使用灰度封面，以接近白色的 250 灰度背景校准整张图和码区，减轻常见浅灰聊天背景中的二维码残影；黑底仍保留可扫描的码块对比。任意背景、转码或压缩后的零残影和可扫描性不能保证。其他处理方式不再强制重绘可见二维码。导出会校验二维码，尺寸不足会提示增大。不要先清理元数据；平台缩小、转码或合并到白底可能破坏透明度和二维码，此时无法保证识别，也无法凭扫描恢复已经丢失的信息。

打码历史采用本地无损 PNG 缓存，最多 50 个状态，总容量预算 256 MiB；大图可能提前减少步数。新编辑清空重做。页面切换使用缓冲绘制及预览合并/缓存来减轻闪烁；图像计算仍使用 CPU，Android 界面沿用系统硬件加速，不要求指定品牌 GPU。

## 背景显图

原色优化按图片对比度和区域颜色逐处限制透色，不再因少量高饱和区域压低整张图的色彩。区域颜色采样提高到最长边 24 像素，色差预算随强度和对比度调整至 16–48 色阶（零强度仍为灰度）；有效色彩强度根据实际合成结果计算，可能低于设置值。仅在原色优化下显示“自定义有效强度”和“恢复自动调节”：手动值覆盖自动降色预算，实际效果仍受色域限制，更高强度可能增加封面透色；恢复自动后重新按图分析。自动封面叠加独立花瓣与流线，并按整图色彩丰富程度增加柔和编织花纹，不沿原图轮廓绘制，也不把这些花纹叠进黑底原图；自选封面不会被替换为花瓣图案。这个方法优先减少透色，因此黑底原图会更淡，细小颜色边界也会改变；不是加密或可靠的信息隐藏。黑白与其他处理方式保留。

Windows 与 Android 均在“双图切换”下方增加独立页面。导入一张或多张黑底图片，即可使用按每张图片尺寸生成的无文字自动封面。封面样式下拉框提供按原图自动配色与自选彩色封面图片；只有选择“轮廓优先（统一色调）”时才显示蓝紫、暖橙、青绿预设配色。自动封面的几何图案采用柔和渐变与少量流线；原色优化下，配色会随原图柔化后的区域颜色变化。选择 **彩色叠显** 或 **黑白显图**，导出透明 PNG。页面不添加文字或编号；输入图片本身已有的文字不会自动删除。效果预览、刷新与适应窗口位于页面最上方。各下拉框下方的说明随选择立即更新；原色优化说明与当前有效强度合并为一处，按窗口宽度适配；刷新参数保持说明区高度与滚动位置稳定，避免重复说明与大块留白。打开自选图片前关闭下拉框，取消选图保留原选择。

两块效果预览显示实际透明合成图片在纯白、纯黑背景下的样子。默认恢复为“原色优化（柔和保色）”，保留原图不同区域的色相和亮度细节，适当弱化细碎色彩与饱和度，避免整张原图套用封面色调。封面随原图的柔化区域颜色形成多色云纹与流线；该方式隐藏固定配色选项，实际封面以预览为准。色彩强度可调，但不能保证完整原色、原亮度或完全没有渗透。“轮廓优先（统一色调）”保留上一版减少轮廓互透的方案；“均衡色彩（原方式）”“原图优先（标准黑底）”仍可手动选择。二维码优化是单独的灰度联动选项。黑白模式独立优化明暗，只生成黑白封面并隐藏彩色专用设置。一个像素只有一份 RGB 和透明度，无法精确表示任意两张独立的完整彩色图。这是视觉效果，不是密码加密。

画布以选中的黑底图片为准，白底图片等比居中适配；透明输入先分别铺到白底或黑底。默认导出最长边 1200 像素，原尺寸受设备内存限制。请保留透明 PNG。转 JPG、截图、查看器使用非纯白/纯黑背景、不同透明度合成方式以及平台重新编码，都可能改变或破坏效果；未承诺真实 QQ/Bilibili 兼容性。

点击“提取白底与黑底显示图”可导出亮度调整后的两幅显示图，不能恢复原文件字节、元数据、原始亮度或全部原始颜色。原“双图切换”还原区也能识别本页导出的透明 PNG。生成和提取均在本机进行，不上传图片、不需要联网。
